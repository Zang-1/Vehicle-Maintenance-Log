# 03 – Activity Diagram

**Người phụ trách:** Lâm · **Đầu vào:** [01 Requirements](../01-requirements/requirements.md), [02 Use Case](../02-use-case/)

Cần nộp activity diagram (có swimlane Người dùng / Hệ thống) cho các luồng:
- Đăng ký, đăng nhập
- Thêm / sửa xe
- Ghi nhận một lần bảo dưỡng (kèm hạng mục, chi phí, hóa đơn)
- Tạo nhắc lịch và hệ thống tự sinh thông báo khi đến hạn
- Xem thống kê chi phí
