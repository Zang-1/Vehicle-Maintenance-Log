# 06 – UI Design trên Figma

**Người phụ trách:** Nguyễn Nam Khoa · **Đầu vào:** [05 Wireframe](../05-wireframe/)

Cần nộp:
- Link file Figma (để quyền xem cho cả nhóm).
- Style guide: bảng màu (có màu cho trạng thái Còn hạn / Sắp đến hạn / Quá hạn và mức LOW / MEDIUM / HIGH), typography, spacing, icon.
- Component: button, input, card xe, bảng lịch sử, badge trạng thái, hộp thông báo lỗi, thanh điều hướng.
- Ảnh xuất `.png` của từng màn hình.

Giao diện sẽ được dựng bằng **Jinja2 templates + CSS thuần** do FastAPI phục vụ (không dùng React). Nên chọn thiết kế dựng được bằng HTML/CSS đơn giản, và dùng font của Google Fonts hoặc font hệ thống.
