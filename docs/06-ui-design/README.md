# 06 – UI Design trên Figma

**Người phụ trách:** Khoa · **Đầu vào:** [05 Wireframe](../05-wireframe/)

Cần nộp:
- Link file Figma (để quyền xem cho cả nhóm).
- Style guide: bảng màu, typography, spacing, icon.
- Component: button, input, card xe, bảng lịch sử, badge trạng thái nhắc lịch, thanh điều hướng...
- Ảnh xuất `.png` của từng màn hình hoàn chỉnh.
