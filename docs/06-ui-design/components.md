# Danh sách component

| Component | Biến thể / trạng thái | Dùng ở màn hình |
|-----------|----------------------|-----------------|
| Nút (Button) | Primary · Secondary · Danger · Disabled | Tất cả |
| Ô nhập (Input) | Bình thường · Lỗi (viền đỏ + dòng báo lỗi) · Có gợi ý bên dưới | S03, S05, S07, S10 |
| Select / Date picker | Bình thường · Lỗi | S03, S04, S05, S07, S08 |
| Textarea kèm bộ đếm ký tự | Bình thường · Lỗi (quá ngắn/dài) | S10 |
| Thẻ (Card) | Có tiêu đề · Không tiêu đề | S01, S02, S04, S06, S08 |
| Thẻ thống kê (Stat card) | Mặc định · Đỏ (quá hạn) · Cam (sắp đến hạn) | S01 |
| Badge trạng thái | Còn hạn · Sắp đến hạn · Quá hạn · Trung tính (Ngừng dùng, Lỗi) · Mức LOW/MEDIUM/HIGH | S01, S02, S04, S09, S10, S11 |
| Bảng (Table) | Có hàng tiêu đề · Căn phải cho số/tiền | S04, S09, S11 |
| Bảng hạng mục có thể sửa | Dòng nhập liệu · Chỉ đọc · Nút xóa dòng | S05, S06 |
| Tab | Đang chọn · Không chọn | S04 |
| Menu bên trái / Thanh điều hướng dưới | Mục đang chọn · Không chọn | Tất cả |
| Hộp thoại xác nhận (Modal) | Xác nhận lưu trữ / xóa | S02b, S04, S06 |
| Khung thông báo (Alert) | Cảnh báo (cam) · Lỗi (đỏ) | S10d–S10g |
| Skeleton đang tải | Dòng chữ giả | S10b |
| Trạng thái rỗng | Biểu tượng + câu hướng dẫn + nút hành động | S02c |
